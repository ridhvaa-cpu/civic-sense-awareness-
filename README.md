# Civic Sense Awareness Website

A responsive civic awareness website built using HTML, CSS and JavaScript.

## Features
- Responsive layout for desktop, tablet and mobile
- Awareness sections about cleanliness, road safety, the environment and public behaviour
- Interactive five-question quiz with score and retry option
- Mobile navigation menu
- Awareness photography

## Run locally
1. Download or clone this repository.
2. Open the `Civic-Sense-Website` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Project files
- `index.html` — page content and structure
- `style.css` — styling and responsive layout
- `script.js` — mobile menu and quiz logic

## Publish with GitHub Pages
1. Push the project to a GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for the Pages deployment to finish. The published URL will appear in the Pages section.

## Image note
The awareness photographs are loaded from Unsplash over the internet, so an internet connection is needed to display them. Replace the image URLs in `index.html` if you want to use your own photographs. Check image licensing and attribution requirements before using images in a public submission.
